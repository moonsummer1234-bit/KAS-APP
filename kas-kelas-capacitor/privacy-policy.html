Kebijakan Privasi — Buku Kas Kelas

Terakhir diperbarui: 16 Agustus 2026

Data yang Dikumpulkan

Aplikasi "Buku Kas Kelas" tidak mengumpulkan, menyimpan di server, atau membagikan data pribadi pengguna kepada pihak ketiga manapun.

Penyimpanan Data

Seluruh data yang dimasukkan pengguna — termasuk nama siswa, catatan kas mingguan, status pembayaran buku/lainnya, dan catatan pengeluaran — disimpan sepenuhnya secara lokal di perangkat pengguna menggunakan penyimpanan lokal aplikasi. Data ini tidak pernah dikirim, diunggah, atau disinkronkan melalui internet ke server manapun.

Penghapusan Data

Data akan terhapus secara otomatis apabila pengguna menghapus data aplikasi (Clear Storage) atau meng-uninstall aplikasi ini dari perangkatnya.

Cadangan Data

Aplikasi menyediakan fitur ekspor/impor cadangan data dalam format file JSON yang tersimpan lokal, sepenuhnya dikontrol oleh pengguna sendiri.

Izin Aplikasi

Aplikasi ini tidak meminta akses ke kamera, lokasi, kontak, atau data sensitif lainnya.

Iklan

Aplikasi ini tidak menampilkan iklan pihak ketiga.
